Deskripsi

**Apa itu Siorma?**
SIORMA adalah sebuah sistem rekrutmen berbasis web yang dirancang untuk mendukung proses
rekrutmen organisasi kampus.

**Lingkup masalah**
Aplikasi ini kami kembangkan untuk mahasiswa Telkom University yang membutuhkan bantuan dalam mencari informasi perekrutan anggota baru ormawa maupun laboratorium
Telkom University, aplikasi ini hadir sebagai penyedia informasi kepada mahasiswa agar mahasiswa tidak ketinggalan informasi seputar ormawa yang mereka minati ataupun
laboratorium Telkom University. Dengan demikian, diharapkan aplikasi ini mampu menjadi platform informasi ormawa maupun laboratorium Telkom University yang efektif dan efisien.
